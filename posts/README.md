# 📥 פוסטים — סרטונים לעבודה

תיקייה ייעודית לעבודה עם Claude על סרטונים לפוסטים (רילס/סטורי לאינסטגרם @ai.gos).

## איך זה עובד

1. **שמים את הסרטון כאן:** גוררים את קובץ הווידאו לתוך התיקייה `posts/videos/`
   (דרך GitHub web → Add file → Upload files, או דרך האפליקציה).
2. **עושים Commit** לענף `claude/generate-post-video-u5ho9g`.
3. **אומרים ל-Claude** איזה קובץ זה ומה רוצים לעשות איתו.

## מה Claude יכול לעשות עם הסרטון

- ✂️ **חיתוך אוטומטי (Quick Cut)** — לקצר סרטון ארוך לרילס קצר וקצבי
- 📐 **התאמת פורמט** — להפוך לאנכי 9:16 לרילס/סטורי (או 1:1 לפיד)
- 🎞️ **חילוץ פריימים** — להוציא תמונת שער (thumbnail) מתוך הסרטון
- 🔊 **שיפור קול/דיבור** — לנקות רעשי רקע מהאודיו
- 📝 **סיכום וזיהוי רגעים** — להבין מה קורה בסרטון ולמצוא את הקטעים הטובים
- ✨ **עיצוב כותרות/אוברליי** — להוסיף טקסט, מסגרת ומיתוג AI.GOS

## פורמטים מומלצים לאינסטגרם

| יעד     | יחס | רזולוציה   |
|---------|-----|------------|
| רילס    | 9:16 | 1080×1920 |
| סטורי   | 9:16 | 1080×1920 |
| פיד     | 1:1  | 1080×1080 |

## תיקיות

- `videos/` — הסרטונים שאתם מעלים (קלט)
- `output/` — תוצרים מוכנים שמייצרים (פלט)
