Hero Intros

חמישה פתיחי אתר קולנועיים, כל אחד כסקיל מלא: טיימליין תנועה עד רמת המילישנייה, מערכת צבע וטיפוגרפיה, פרומפטים להפקת הווידאו, וקוד שמוטמע בכל אתר. מנוע אחד, בלי ספריות.

01

בוחרים פתיח

צופים בתבנית החיה למטה. בפתיחים עם גלילה, גוללים בתוך התצוגה.

02

מורידים את הסקיל

ZIP עם SKILL.md, תבנית ומנוע. מעלים ל‑Claude (Settings → Skills) או מעתיקים לפרויקט.

03

מפיקים ומטמיעים

מייצרים את הווידאו לפי הפרומפט, מקודדים לפי הפקודה, ומחליפים את src. זהו.

The Engine · hero-intro.js

כל חמשת הפתיחים רצים על אותו מנוע (4KB, vanilla). תנועה מוגדרת ב‑HTML עם data attributes, כך שאפשר לבנות פתיח חדש בלי לכתוב JavaScript.

<link rel="stylesheet" href="hero-intro.css">
<section data-hero data-scroll="260">              <!-- scroll length in vh · 0 = intro only -->
  <div class="hi-stage">
    <video class="hi-video" data-hero-video data-mode="scrub" muted playsinline src="hero.mp4"></video>
    <h1 data-in="letters" data-fx="rise" data-at="200" data-stagger="90">Secret</h1>
    <nav data-in="drop" data-at="900" data-ease="back">…</nav>
    <div data-scroll-range="0.45,1">Chapter two</div>
  </div>
</section>
<script src="hero-intro.js"></script>

data-in     fade-up · fade · blur · scale · drop · rise · line · slide-r · slide-l · letters · words
data-fx     child effect for letters/words  (letter-blur · rise · slide-l · fade-up …)
data-ease   out (expo) · back (overshoot) · inout · soft
CSS hooks   --p (scroll 0→1) · .hi-started · .has-video · .hi-reduced
Test        any-template.html?video=https://your-cdn/clip.mp4

# scrub-ready encode (every frame a keyframe)
ffmpeg -i in.mp4 -vf "scale=1920:-2,fps=30" -c:v libx264 -crf 22 -preset slow \
  -x264-params keyint=1:scenecut=0 -pix_fmt yuv420p -movflags +faststart -an hero-scrub.mp4
